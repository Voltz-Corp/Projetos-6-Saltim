# Config

Esta pasta guarda parametros de configuracao do pipeline de dataset.

## Arquivo atual

- `dataset_config.json`

## Parametros cobertos

- datas de inicio e fim da ABT;
- categoria excluida de compra direta, como `CAT0015`;
- horizonte de previsao;
- ciclo de revisao;
- fator de safety stock;
- janelas moveis;
- datas de split temporal para treino, validacao e teste.
